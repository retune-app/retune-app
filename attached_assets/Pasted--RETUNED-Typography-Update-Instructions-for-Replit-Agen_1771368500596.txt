## Brand Typography System (Hybrid Approach)

**Key principle:** Cormorant Garamond for big statement headlines (h1, h2). Outfit Bold for smaller action-oriented headings (h3, h4, card titles, timeline steps). This ensures large headlines feel elegant while smaller headings stay punchy and readable.

|Role                     |Font              |Weight                    |Size                      |Spacing                         |
|-------------------------|------------------|--------------------------|--------------------------|--------------------------------|
|Nav wordmark “RETUNED”   |Outfit            |500                       |17px                      |letter-spacing: 4.5px, uppercase|
|Nav links & CTA button   |Outfit            |500                       |14px                      |—                               |
|Hero headline (h1)       |Cormorant Garamond|600                       |32px mobile / 48px desktop|letter-spacing: -0.5px          |
|Section headlines (h2)   |Cormorant Garamond|600                       |26px mobile / 36px desktop|letter-spacing: -0.3px          |
|Subsection headlines (h3)|**Outfit**        |**700**                   |20px mobile / 24px desktop|letter-spacing: -0.2px          |
|h4                       |**Outfit**        |**600**                   |18px mobile / 20px desktop|—                               |
|Timeline step titles     |**Outfit**        |**700**                   |20px                      |letter-spacing: -0.2px          |
|Feature card titles      |**Outfit**        |**700**                   |20px                      |letter-spacing: -0.2px          |
|Body text (p)            |Outfit            |400                       |16px                      |line-height: 1.6                |
|Buttons & CTAs           |Outfit            |500                       |14px                      |letter-spacing: 0.3px           |
|Pills / tags / badges    |Outfit            |400                       |12px                      |letter-spacing: 0.5px           |

|Footer                   |Outfit            |400                       |inherit                   |—                               |

## Step 1: Replace Google Fonts Import

Find the current font import in the HTML `<head>` (likely loads Space Grotesk, Inter, and/or Nunito).

**Remove the old import. Replace with:**

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@400;500;600;700&family=Outfit:wght@300;400;500;600;700&display=swap" rel="stylesheet">
```

If fonts are imported via CSS `@import`, replace that instead:

```css
@import url('https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@400;500;600;700&family=Outfit:wght@300;400;500;600;700&display=swap');
```

-----

## Step 2: Global CSS Overrides

Add these base styles. They should override all existing font declarations:

```css
/* ============================================
   RETUNED TYPOGRAPHY SYSTEM — Feb 2026
   HYBRID: Cormorant Garamond (h1, h2) + Outfit Bold (h3, h4) + Outfit (body)
   ============================================ */

body {
  font-family: 'Outfit', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
  font-weight: 400;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

/* BIG statement headlines — elegant serif */
h1, h2 {
  font-family: 'Cormorant Garamond', Georgia, 'Times New Roman', serif;
  font-weight: 600;
  line-height: 1.2;
}

/* SMALLER action headings — bold sans-serif for punch and readability */
h3, h4, h5, h6 {
  font-family: 'Outfit', -apple-system, BlinkMacSystemFont, sans-serif;
  font-weight: 700;
  line-height: 1.3;
}

h4, h5, h6 {
  font-weight: 600;
}

p, li, td, th, label, input, textarea, select, span, a, div {
  font-family: 'Outfit', -apple-system, BlinkMacSystemFont, sans-serif;
}

button, [class*="btn"], [class*="button"], [class*="cta"] {
  font-family: 'Outfit', sans-serif;
  font-weight: 500;
}

code, pre, kbd, samp {
  font-family: 'SF Mono', 'Fira Code', 'Consolas', monospace;
}
```

## Step 3: Find-and-Replace Old Font References

Search the ENTIRE codebase (CSS, JS, HTML, JSX) and replace:

```
'Space Grotesk'  →  'Cormorant Garamond'   (when used for headlines/headings)
'Space Grotesk'  →  'Outfit'               (when used for body/UI)
"Space Grotesk"  →  (same logic as above)
'Inter'          →  'Outfit'
"Inter"          →  "Outfit"
```

After replacing, verify font-weight values:

- Space Grotesk used for h1/h2 at `700` → change to `600` for Cormorant Garamond
- Space Grotesk used for h3/h4/card titles at `700` → keep as Outfit `700` (bold sans)
- Inter body at `400` or `500` → keep same for Outfit (same weights work)

**CRITICAL:** Do NOT apply Cormorant Garamond to h3, h4, card titles, timeline step titles, or feature headings. These must stay as Outfit 700 (bold sans-serif) for readability and impact at smaller sizes.

If `Nunito` is referenced for landing page elements, replace with `Outfit`. Leave any Nunito references in React Native / app code alone.
