## Part 2: Landing Page Typography Update

### Summary of Changes

| Context | OLD Font | NEW Font | Google Fonts URL |
|---------|----------|----------|------------------|
| Headlines (h1, h2, h3) | Space Grotesk | **Instrument Serif** | `Instrument+Serif:ital@0;1` |
| Body text (p, li, td) | Inter | **DM Sans** | `DM+Sans:wght@400;500;600;700` |
| Accent text / labels | Nunito | **DM Sans 500** (or keep Nunito) | Already loaded with DM Sans |

### Step-by-Step Implementation

#### 1. Update the Google Fonts import

Find the existing font import in the `<head>` of your HTML (or in your CSS file). It likely looks something like:

```html
<!-- REMOVE THIS -->
<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700&family=Inter:wght@400;500;600&family=Nunito:wght@400;700&display=swap" rel="stylesheet">
```

Replace with:

```html
<!-- ADD THIS -->
<link href="https://fonts.googleapis.com/css2?family=Instrument+Serif:ital@0;1&family=DM+Sans:wght@400;500;600;700&family=Nunito:wght@400;700&display=swap" rel="stylesheet">
```

Note: Nunito is kept for any accent elements that should bridge to the in-app experience.

#### 2. Update CSS font-family declarations

Find and replace these CSS rules. The exact selectors may vary based on your codebase, but here are the key changes:

```css
/* ============================================
   TYPOGRAPHY UPDATE: Space Grotesk → Instrument Serif
   ============================================ */

/* HEADLINES — Replace Space Grotesk with Instrument Serif */
/* Find any rule that sets font-family to 'Space Grotesk' and replace */

h1, h2, h3 {
  font-family: 'Instrument Serif', Georgia, serif;
  /* Remove any letter-spacing that was tuned for Space Grotesk */
  /* Instrument Serif looks best with tighter or default letter-spacing */
}

/* Main hero headline */
h1 {
  font-family: 'Instrument Serif', Georgia, serif;
  font-weight: 400; /* Instrument Serif only has 400 weight — it's naturally elegant */
  letter-spacing: -0.5px; /* Optional: slightly tighter for large display sizes */
}

/* Section headlines */
h2 {
  font-family: 'Instrument Serif', Georgia, serif;
  font-weight: 400;
}

/* Subsection headlines */
h3 {
  font-family: 'Instrument Serif', Georgia, serif;
  font-weight: 400;
}

/* ============================================
   BODY TEXT: Inter → DM Sans
   ============================================ */

/* Find any rule that sets font-family to 'Inter' and replace */

body {
  font-family: 'DM Sans', -apple-system, BlinkMacSystemFont, sans-serif;
}

p, li, td, th, label, input, textarea, select, button {
  font-family: 'DM Sans', -apple-system, BlinkMacSystemFont, sans-serif;
}

/* Navigation links */
nav, nav a {
  font-family: 'DM Sans', sans-serif;
  font-weight: 500;
}

/* Buttons */
button, .btn, a.btn, [class*="button"] {
  font-family: 'DM Sans', sans-serif;
  font-weight: 600;
}

/* Small labels, tags, metadata */
.tag, .label, .caption, small, .meta {
  font-family: 'DM Sans', sans-serif;
  font-weight: 500;
}

/* Footer */
footer, footer * {
  font-family: 'DM Sans', sans-serif;
}

/* ============================================
   ACCENT TEXT (optional: keep Nunito or switch to DM Sans)
   ============================================ */

/* If you have specific accent elements using Nunito that should
   maintain the bridge to the in-app feel, keep them as Nunito.
   Otherwise, DM Sans 500 works as a clean replacement. */
```

#### 3. Global find-and-replace (fastest method)

If your landing page CSS is in a single file or a few files, do these find-and-replace operations:

```
Find:    'Space Grotesk'
Replace: 'Instrument Serif'

Find:    "Space Grotesk"
Replace: "Instrument Serif"

Find:    'Inter'
Replace: 'DM Sans'

Find:    "Inter"
Replace: "DM Sans"
```

**Important:** After replacing, also update font-weight values for headlines. Space Grotesk uses `font-weight: 600` or `700` for bold headlines, but Instrument Serif only comes in weight `400` — and it looks best that way. Remove or change any `font-weight: 600/700` on headline elements to `font-weight: 400`.

#### 4. Apply to ALL pages

These font changes should apply to every page on retuned.app:
- **Main landing page** (`/` or `index.html`)
- **Science page** (`/science`)
- **Support page** (`/support`)
- **Privacy Policy / Terms of Service** (if they share the same stylesheet, they'll update automatically)

If each page has its own CSS or font import, repeat steps 1-3 for each page.

#### 5. Verify after deployment

After implementing, check:
- [ ] Hero headline renders in Instrument Serif (serif font, elegant, weight 400)
- [ ] Body text renders in DM Sans (clean sans-serif, slightly rounder than Inter)
- [ ] Buttons and nav use DM Sans 500/600
- [ ] No leftover references to Space Grotesk or Inter in CSS
- [ ] Google Fonts import loads Instrument Serif + DM Sans + Nunito
- [ ] Pages load without FOUT (flash of unstyled text) — add `font-display: swap` if needed
- [ ] Science page (`/science`) uses same fonts
- [ ] Support page (`/support`) uses same fonts

### Why These Fonts

- **Instrument Serif** — Warm, elegant, distinctive. No other wellness app uses a serif headline. Pairs naturally with the gold + navy Resonance Rings logo. Only comes in weight 400, which forces elegant restraint.
- **DM Sans** — Warmer and more humanist than Inter, with rounder letterforms. Highly legible at all sizes. Pairs well with Instrument Serif without competing.
- **Nunito (kept for accents)** — Maintains visual bridge to the in-app experience where Nunito is the primary font.
