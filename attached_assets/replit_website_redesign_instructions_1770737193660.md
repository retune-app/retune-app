# REPLIT AGENT: RETUNED Website Redesign Instructions
## Objective: Transform Feature-List Site into Integrated Experience Platform

---

## PROJECT OVERVIEW

**Current Problem:**
The RETUNED website presents the app as a collection of separate features (voice cloning, breathing, affirmations, RSVP) instead of communicating the core innovation: an adaptive wellness system where each practice flows into the next.

**Redesign Goal:**
Position RETUNED as the first wellness app with an integrated Breathe-Believe-Meditate feedback loop—where affirmations become breathwork mantras, breathing sessions transition into guided meditations, and meditations reconnect to personalized affirmations based on mood.

**Key Messaging Shift:**
- FROM: "We have AI voice cloning + breathing exercises + affirmations"
- TO: "The first wellness app that knows what you need next"

---

## DESIGN PRINCIPLES

### 1. **Show Flow, Not Features**
- Use circular diagrams and animated transitions to illustrate how modes connect
- Replace static feature checklists with journey-based narratives
- Emphasize continuity over capabilities

### 2. **Context-Aware Language**
- Every section should reinforce "your state travels with you"
- Avoid isolated feature descriptions
- Use phrases like "carries forward," "flows into," "adapts to"

### 3. **Reduce Cognitive Load**
- Eliminate "what do I choose?" anxiety in copy
- Position the app as intelligent guide, not menu of options
- Simplify navigation, emphasize guided experience

## **SECTION 7: THE TECHNOLOGY (Optional Deep-Dive Section)**

### Title:
```
Built Different: The Tech Behind the Flywheel
```

### Accordion/Expandable Sections:

#### **AI Voice Synthesis**
```
Your voice is synthesized using advanced neural audio models—creating affirmations that 
sound naturally like you, not robotic text-to-speech. The same voice quality carries 
across all three modes.
```

#### **Mood-to-Meditation AI**
```
When you report your emotional state, a language model generates a personalized meditation 
script in real-time—addressing your specific needs instead of serving a generic recording.
```

#### **RSVP (Rapid Serial Visual Presentation)**
```
Meditation words appear one at a time, synced to audio playback. This keeps your visual 
focus anchored, reducing mind-wandering and deepening comprehension.
```

#### **State Persistence Engine**
```
Behind the scenes, the app maintains a session context object—tracking your active 
affirmation, mood, playback position, and transition history. This enables seamless 
handoffs between modes.
```

#### **Smart Tag Matching**
```
Every affirmation is tagged with emotional pillars (calm, confidence, motivation). After 
meditation, an algorithm scores your mood against your affirmation library to suggest 
the best match.
```

## DESIGN SYSTEM GUIDELINES

### **Color Palette:**
- **Primary (Believe):** Warm tone (amber, gold, or soft coral)
- **Secondary (Breathe):** Cool tone (teal, sky blue, or lavender)
- **Tertiary (Meditate):** Grounded tone (forest green, deep purple, or slate)
- **Background:** Off-white or very light gray (#FAFAFA)
- **Text:** Charcoal (#2C2C2C), not pure black

### **Typography:**
- **Headings:** Clean sans-serif (Inter, Manrope, or Outfit)
- **Body:** Readable sans-serif (Inter, Open Sans, or System UI)
- **Accent/Quotes:** Optional serif for testimonials (Lora, Merriweather)

### **Spacing:**
- Generous whitespace between sections (100-150px vertical padding)
- Mobile: Reduce to 60-80px vertical padding
- Consistent horizontal padding (10-15% of screen width on desktop)

### **Motion/Animation:**
- Subtle scroll-triggered animations (fade-in, slide-up on 200ms delay)
- Circular flywheel diagram: Animates on scroll-into-view
- Avoid auto-playing animations or looping videos (distracting, not calming)

### **Accessibility:**
- WCAG AA minimum contrast ratios
- All interactive elements have focus states
- Images have descriptive alt text
- Ensure responsive breakpoints: 320px, 768px, 1024px, 1440px
